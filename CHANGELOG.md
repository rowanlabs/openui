# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - released

### Added

- `NeuralOrbView`, an animated dotted orb with configurable color, thinking state and animation control.
- `OceanWaveView`, an animated water card with XML and Java configuration for its wave, container, borders, icon and TextView-like label.
- `MoreAppsView`, a configurable app recommendation list backed by a JSON endpoint, persistent response cache, loading skeleton and icon caches.
- `MoreAppsView.AppItem`, `OnAppClickListener` and `OnLoadListener` for accessing loaded app data and customizing click/load behavior.
- `RowanUi.VERSION`, `RowanUi.setDebug(boolean)` and `RowanUi.isDebug()` for SDK version access and optional Logcat diagnostics.
- README documentation for every SDK class, view, custom XML attribute, public API and the app-list JSON format.

This is the initial SDK release version and has not been published. The dependency and SDK version remain `1.0.0`.
